# Data

All data in this folder is **synthetic**, generated by the scripts in `python/data_generation/`. The random seed is fixed, so every run reproduces the same files.

| Folder | Contents | Who writes it | Who reads it |
|---|---|---|---|
| `raw/` | "Source system" extracts with realistic data-quality problems (duplicates, inconsistent supplier names, missing values, bad dates, outliers) | `python/data_generation/` | `python/cleaning/` |
| `processed/` | Cleaned, validated, analysis-ready tables in star-schema shape | `python/cleaning/` | PostgreSQL load scripts, Python analysis, Excel, Power BI |

Raw files are never edited by hand. Every change between `raw/` and `processed/` is made by code and logged, so any number in the dashboard can be traced back to its source row.

The table list, grain and column definitions are documented in `docs/DATA_MODEL.md` and `docs/DATA_DICTIONARY.md` (built in Phase 4).
